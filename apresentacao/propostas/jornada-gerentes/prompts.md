## Imagem 1 — Antes do envio

Use case: ui-mockup. Create one beautiful, realistic, HIGH-FIDELITY DESKTOP WEB APP SCREENSHOT mockup, 1600x900 landscape, frontal flat screen, no perspective, no laptop frame, no phone mockup. Reference image is the current Pix POC app; retain its actual product identity and functionality, but greatly simplify the presentation for bank managers watching a projector. This is a proposed demo-mode UI, not a marketing page. Large legible Portuguese text, immaculate typography, generous space, no decorative illustration. Palette white and very pale cool gray, BV royal blue #002BAB and deep navy #001A6B, tiny muted green for success or muted red for blocked outcomes. No gradients, no neon, no icon shield, no brand mascot. Top horizontal header only simple tab labels Jornada (selected), Ao vivo, Comparar, Operação, and a quiet Ajustes link at far right; no logo, no slogan, no engine radio buttons, no animation switches, no health status, no speed controls, no occurrence counters. Main heading at upper left 'Jornada do Pix', small understated 'Modo apresentação' at top right. Main body two columns: left 32% width for a simple clean single Pix input form, right 68% for a generous flat process diagram and outcome. The left form shows label 'Cenário' and a compact dropdown showing 'Ameaça', amount 'R$ 0,50' in large type, label 'Mensagem', and quote 'Você vai se arrepender se não me responder.' in a spacious readable textarea. No CPF, names, account data, timestamps or transaction IDs. Main action at bottom of left form 'Enviar Pix' in royal blue. Right area has a clear horizontal 4-step process with thin connectors and simple outline icons. Exact labels in order 'Precisa analisar?', 'Desofuscação', 'Decision Model', 'Decisão'. Four comfortably spaced steps, one row, large labels. No milliseconds, no fake latency, no model percentages, no technical API fields or logs. NO extra sidebar, no charts, no metrics grid. Restrained, calm, extremely easy to understand, all visible interface Portuguese. Avoid tiny typography. STATE: BEFORE SENDING. All four stages neutral light gray, each status 'Aguardando'. Underneath the process, one short calm instructional line 'Envie o Pix para acompanhar a análise.' Plenty of negative space. Button enabled. No result banner yet. No red threat highlighting until analysis. Entire screen composed as a crisp professional enterprise banking app with very readable labels.
